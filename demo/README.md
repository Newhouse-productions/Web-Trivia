## 📞 Support & Troubleshooting

### **Issue:** Logo looks pixelated on projection
**Solution:** Make sure projector is 1920×1080 or higher; test dark logo from back of venue

### **Issue:** Banner colours don't match on screen
**Solution:** Check screen colour profile (should be sRGB, not CMYK); adjust brightness

### **Issue:** Questions feel too easy/hard**
**Solution:** Use question bank to swap in harder/easier questions; swap points values

### **Issue:** Table layout doesn't fit our venue
**Solution:** Modify seats/table counts in config JSON before importing

### **Issue:** Need custom background for logo
**Solution:** Use `logo-bswp-original.png` as base; see LOGO-GUIDE.md for customisation

### **Issue:** Running out of time during marking
**Solution:** Use alias lists aggressively; see paint-the-town-guide.md section on aliases
